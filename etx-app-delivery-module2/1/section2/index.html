Git Version Control

What’s in this section?

In this section, you’ll learn why Git version control is a foundational capability of a modern Application Platform and how it enables collaborative software development, CI/CD pipelines, and GitOps-based deployments.

If you’re already comfortable using Git and common branching strategies, feel free to skim this lesson and continue to Lab 1: Initial Setup. The concepts introduced here provide useful context for the Software Factory you’ll build throughout this course.
