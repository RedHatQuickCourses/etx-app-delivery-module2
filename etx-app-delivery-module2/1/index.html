Software Factory Foundations with OpenShift Dev Spaces

Introduction

Welcome to this quick course on the Software Factory Foundations with OpenShift Dev Spaces. This course is the second in a series of six courses about Application Platform Delivery:

  • Application Platform Delivery Foundations

  • Software Factory Foundations with OpenShift Dev Spaces (This course)

  • Software Factory and CI/CD

  • Application Modernization

  • Developer Hub and Platform Engineering

  • Trusted Software Supply Chain (TSSC)

What’s in this course?

In this module, you’ll learn how an Application Platform enables a Software Factory and why Git is fundamental to modern application delivery. You’ll prepare the required platform services, configure a cloud-native development environment using Red Hat OpenShift Dev Spaces and GitLab, and deploy the ETX App Base application.

By the end of this module, you’ll have a fully configured development environment and a running application that you’ll use throughout the remainder of this learning path.

Duration: 3:00 hours

Objectives

On completing this course, you should be able to:

  • Explain how an Application Platform enables a Software Factory for standardized software delivery.

  • Describe the role of Git in collaborative development, CI/CD pipelines, and GitOps workflows.

  • Configure Red Hat OpenShift Dev Spaces and integrate it with GitLab.

  • Create and use a reusable Devfile to provision cloud-native development workspaces.

  • Launch a browser-based development environment and connect it to the application platform.

  • Deploy the ETX App Base application and verify that it is running successfully.

Prerequisites

This course assumes that you have the following prior experience:

  1. Red Hat OpenShift Container Platform (OCP) Technical Overview or Kubernetes Basics
