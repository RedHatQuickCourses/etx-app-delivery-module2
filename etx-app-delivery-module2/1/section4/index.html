DevEx and DevSpaces

What’s in this section?

In this section, you prepare a complete cloud-native development environment using Red Hat Dev Spaces and GitLab.

You install and configure Red Hat Dev Spaces, integrate it with GitLab, create a reusable Devfile, and launch the ETX App Base application in a browser-based development workspace connected to the supporting platform services.
