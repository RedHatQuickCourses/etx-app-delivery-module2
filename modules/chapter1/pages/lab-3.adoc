= Lab 7: Install and Verify Red Hat DevSpaces
:navtitle: Lab 7: Install Red Hat DevSpaces

== Install using the OperatorHub

. In the OpenShift Web Console, go to menu:Ecosystem[Software Catalog]
. Search for *Red Hat OpenShift Dev Spaces*
. Click btn:[Install]
. Keep the operator installation namespace as `openshift-operators`
. Accept the defaults for the rest (All namespaces, Automatic approval) and click btn:[Install]
. Wait for the operator to reach the `Succeeded` phase

.Dev Spaces Operator Installed(_Click the image to view it in full size in a new browser tab_)
image::devs.png[link={imagesdir}/devs.png, width=500]


== Verify

Verify from the CLI:

[source,bash,role=execute]
----
oc get csv -n openshift-operators | grep devspaces
----

A similar output should be displayed:

[bash]
----
devspacesoperator.v3.27.1           Red Hat OpenShift Dev Spaces   3.27.1    devspacesoperator.v3.27.0           Succeeded
----

The DevWorkspace Operator is installed automatically as a dependency.

NOTE: The operator runs from `openshift-operators`. The `openshift-devspaces` namespace will be created in the next step for the `CheCluster` instance and Dev Spaces server components.
